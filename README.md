# U-Fund: Paws & Causes 🐾

A full-stack charitable giving platform built as a team project for SWEN-261 (Software Engineering) at RIT, following an Agile/Scrum process across multiple sprints.

## Overview

Paws & Causes is a U-Fund web application that lets organizations post funding "needs" and allows donors to browse, add needs to a basket, and check out to fulfill them — modeled after a nonprofit crowdfunding platform, with a focus on animal welfare organizations.

## Tech Stack

- **Backend:** Java, Spring Boot (REST API)
- **Frontend:** Angular
- **Version Control / Process:** Git, GitHub, Agile/Scrum, Kanban board

## My Contributions

- Implemented backend search functionality for needs.
- Built Angular views for the cupboard (need listing) and basket (checkout flow).
- Coordinated user stories and sprint planning for sprints

## Project Structure

Developed iteratively across three sprints, with feature work done on separate branches (see branch list) before merging into `main`. Tags `v2.0`–`v4.0` mark major sprint milestones.

## Team Project Note

This was a collaborative team project completed as part of RIT's SWEN-261 curriculum. This repo is a mirror of the original team repository, preserved with full commit history for portfolio purposes.

## Getting Started

```bash
# Backend
cd api
mvn spring-boot:run

# Frontend
cd frontend
npm install
ng serve
```

*(Adjust paths above to match your actual folder structure once you check the repo.)*
